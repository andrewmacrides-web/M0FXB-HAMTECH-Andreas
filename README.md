# M0FXB HamTech Dashboard for ASL3

HamTech AllStar Control Panel for ASL3.

## Quick Install

SSH into your ASL3 node using PuTTY and run:

    wget -qO- https://raw.githubusercontent.com/andrewmacrides-web/M0FXB-HAMTECH-Andreas/main/install.sh | sudo bash

Follow the on-screen installation prompts.
